# Elvis Wang — Personal Portfolio

Website: https://zxwang0501-droid.github.io/

## Updating the website

Edit `projects.js` to add future projects. Edit `index.html` for the biography and detailed case study. Styling lives in `styles.css`; interactions live in `app.js`.

GitHub Pages publishes the root of the `main` branch automatically. Changes can take a few minutes to appear.

## Local preview

Run `python3 -m http.server 8000` and visit http://localhost:8000.
